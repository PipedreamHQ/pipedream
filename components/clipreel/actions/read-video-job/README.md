# Read Video Job

Get the current status and result of a [ClipReel](https://www.clipreel.com/) edit or render job. Use the job ID returned by **Draft a Video Edit** or another ClipReel job request.

Connect a token with Project read. If the job is still queued or running, wait before checking again. Results may contain short-lived private links. Keep them in the workflow or share them only with the project’s intended reviewers.
