# Overview

[PixelPanda](https://pixelpanda.ai) is an AI image platform for e-commerce and creators. These components let you process images in Pipedream workflows: remove backgrounds, AI-upscale up to 8x, enhance, remove text/watermarks, and transform images with a text prompt.

# Getting Started

1. Create a free account at [pixelpanda.ai](https://pixelpanda.ai) and copy your API key from Profile → API.
2. Connect the PixelPanda app in Pipedream and paste the key.

Each operation costs PixelPanda credits (1 credit per image; prompt edits 2). Credits never expire.

# Example Use Cases

- Clean up user-submitted product photos before publishing them to your store
- Auto-upscale AI-generated art for print-on-demand fulfillment
- Strip watermarks/text from images arriving in a Slack or Drive workflow
