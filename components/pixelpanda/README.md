# Overview

The PixelPanda API turns plain product images into marketing assets with AI: background removal, upscaling, photo enhancement, prompt-based editing, AI product-scene photos, complete ad packs from a product URL, and UGC-style talking videos with native lip-sync. Use it on Pipedream to enrich images the moment they land in your store, spreadsheet or storage bucket, and route the finished assets anywhere.

# Example Use Cases

- **Shopify listing enrichment**: When a new product is created in Shopify, remove the background, upscale to 4x and generate four AI lifestyle scene photos, then write the URLs back to the product.
- **Ad pack on autopilot**: Drop a product page URL into a Google Sheet and get back scene photos, eight static ads, captions and a lip-synced UGC video for the product.
- **Bulk image cleanup**: For every image uploaded to Dropbox or S3, enhance it, remove the background and save the transparent PNG back to storage.

# Getting Started

Sign up at [pixelpanda.ai](https://pixelpanda.ai), open your Profile and copy the API key under **API Token** (it starts with `pk_live_`). Paste it into the PixelPanda app on Pipedream when connecting your account. Each action spends PixelPanda credits at the same rate as the web app.
