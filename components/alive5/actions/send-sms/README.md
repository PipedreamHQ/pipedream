# Overview

Send a text message from an Alive5 business SMS number.

# Getting Started

Connect Alive5, select an SMS number, then choose a sending user assigned to that channel. Enter a recipient with a country code and the text to send. Only send to recipients who have consented to your messages.

The result contains Alive5's message ID, status, thread ID, sender, recipient, and message data.

# Troubleshooting

Refresh the sending-user choices when changing SMS numbers. Check the Alive5 conversation after a timeout before retrying, since the first request may have sent the message. Carrier delivery is separate from API acceptance.
