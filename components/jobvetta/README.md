# Overview

Jobvetta is a global employer job search and hiring intelligence API covering 6.5M+ live verified openings across 238,000+ companies in 242 countries. Connect Jobvetta in Pipedream workflows or AI Agents to search verified career-site postings, monitor hiring velocity at target accounts, retrieve full 70+ field job requirements, and calculate P25/median/P75 market salary benchmarks.

# Example Use Cases

- **Real-time job alerts**: Trigger a workflow with New Job Matching Search whenever a role matching your keywords and location goes live, enrich it with Get Job Details, and post to Slack or email.
- **B2B sales and account enrichment**: When a new lead enters your CRM, run Get Company Hiring Signals to see total open headcount and active engineering or security hiring.
- **Compensation benchmarking**: Query Estimate Salary inside an AI agent or recruiting workflow to retrieve live P25, median, and P75 base salary data from disclosed employer postings.

# Getting Started

Visit [jobvetta.com/api](https://www.jobvetta.com/api) to generate a free API key (25 requests per day, no credit card required) and paste the `jvk_...` key when connecting your Jobvetta account in Pipedream.
