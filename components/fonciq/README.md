# Overview

Fonciq connecte vos automatisations au Registre foncier du Québec et aux données foncières publiques du Québec. Service indépendant, non affilié au gouvernement du Québec ni au Registre foncier.

Fonciq connects your automations to the Québec land registry and Québec public land data. Independent service, not affiliated with the Government of Québec or the land registry.

# Getting Started

Créez une clé d'API dans Fonciq Studio › Développeurs, puis connectez votre compte Fonciq dans Pipedream. / Create an API key in Fonciq Studio › Developers, then connect your Fonciq account in Pipedream.

- Documentation: https://api.fonciq.ca/plateforme
