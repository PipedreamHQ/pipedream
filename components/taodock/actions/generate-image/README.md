# Overview

Generate one or more images from a text prompt using a Taodock image model. The action returns the generated images as base64 (`b64_json`) or URLs, depending on the model.

# Example Use Cases

- Generate a blog header image when a new CMS post is created.
- Produce product mockups from a prompt stored in a sheet row.
- Create daily social media visuals on a schedule and post them to Slack.

# Getting Started

Connect your Taodock account with an API key from the [Taodock console](https://taodock.com/keys), pick an image-capable model from the dropdown, and write a prompt. Use the optional fields (size, aspect ratio, quality, output format, count, seed) to control the result.
