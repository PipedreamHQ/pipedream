# Overview

The Autom API is a search engine results API that returns structured JSON from Google, Bing, Brave, Yahoo and DuckDuckGo. In Pipedream, you can run web searches, read Google News articles, find places on Google Maps, collect Google autocomplete suggestions and look up Google location names, then pass the results to any other app in your workflow.

# Example Use Cases

- **Track Keyword Rankings**: Run a scheduled workflow that searches Google for each of your target keywords, records the position of your domain in Google Sheets, and posts ranking changes to Slack.

- **Monitor News Coverage**: Search Google News every morning for your brand and your competitors, summarize the new articles with an AI step, and email the digest to your team.

- **Build Local Lead Lists**: Search Google Maps for a business type in a list of cities and write each place with its address, phone number and website to your CRM.

- **Find Keyword Ideas**: Collect Google autocomplete suggestions for seed keywords and group them into content topics in Notion.
