# Overview

Groundsocial is a social and web data API. One API key and one credit balance give you public posts, comments, profiles, transcripts and search results from 80+ platforms, including Reddit, X, TikTok, Instagram, YouTube, LinkedIn, Hacker News, GitHub, Google and Amazon. Each response keeps the platform's own JSON shape. In Pipedream you can pull that data into any workflow: watch a topic, enrich a lead, or feed posts to an LLM step.

# Example Use Cases

- **Brand monitoring**: On a schedule, search Reddit for your product name with Search Reddit Posts, filter new posts in a code step, and send them to Slack.
- **Video notes**: When a YouTube link arrives in a form or chat, get its transcript with Get YouTube Transcript, summarize it with an LLM step, and save the summary to Notion.
- **Any platform**: Use Find Endpoints to look up the endpoint for a task (free), then Call Endpoint to read TikTok comments, Instagram profiles, Google results or any of the other ~590 endpoints.

# Getting Started

Sign up at [groundsocial.dev](https://groundsocial.dev/app/sign-in?new=1) (100 free credits, no card), create an API key in the dashboard, and paste it when you connect the Groundsocial app. Failed calls are not charged.
