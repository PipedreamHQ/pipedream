# Search Google

Run Search Google with a connected AceDataCloud account. Enter the required input in this action. The full API response is returned to the next Pipedream step. Use a token with access to this service or a global token and check current pricing before running a request.

This source action awaits Pipedream App registration in [issue #22155](https://github.com/PipedreamHQ/pipedream/issues/22155). A green repository check does not prove a real connected call.
