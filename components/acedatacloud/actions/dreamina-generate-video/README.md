# Generate Dreamina Video

Create a lip-synced Dreamina video from a portrait and audio through Ace Data Cloud. [See the documentation](https://platform.acedata.cloud/documents/dreamina-videos)

Choose this action under the AceDataCloud connection and configure its native fields. This Beta service requires account access. Use only reference media you are authorized to submit. The action sends one request, returns the original task ID with `state: submitted`, and does not automatically retry or poll. Inspect your own Ace task history for the completed result.
