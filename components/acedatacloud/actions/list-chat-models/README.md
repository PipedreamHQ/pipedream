# Overview

List the chat models present in both the [public Ace Data Cloud model catalog](https://platform.acedata.cloud/models?utm_source=opensource&utm_medium=referral&utm_campaign=evergreen) and the authenticated Models API. This action only reads the model lists.

# Getting Started

1. Connect your [Ace Data Cloud application API token](https://platform.acedata.cloud/console/applications?utm_source=opensource&utm_medium=referral&utm_campaign=evergreen).
2. Run the action to get the matching model IDs and labels. Use an ID from the result in **Chat With Model**.

# Troubleshooting

If an expected model is missing, check both lists for its exact ID. Model access and balance are checked when you make a chat request.
