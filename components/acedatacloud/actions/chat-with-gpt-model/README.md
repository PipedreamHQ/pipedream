# Overview

Choose **Chat With Model** under AceDataCloud to send one text prompt through Ace Data Cloud. It exposes a native **Model** selector, Prompt, optional System Prompt and Max Tokens. It does not require a custom HTTP URL and is not a global Pipedream model-provider setting.

# Getting Started

After [official registration/publication](https://github.com/PipedreamHQ/pipedream/issues/22155), connect your raw [Ace API Token](https://platform.acedata.cloud/console/applications?utm_source=opensource&utm_medium=referral&utm_campaign=evergreen&utm_content=pipedream_readme_api_key) in the `api_key` secret field and select that account. Refresh Model options, choose an eligible chat model, enter a prompt and optionally limit output tokens. Options are the intersection of the connected `/v1/models` response and published typed chat catalog. Current catalog visibility does not grant permission or promise availability; check [service price and balance](https://platform.acedata.cloud/models?utm_source=opensource&utm_medium=referral&utm_campaign=evergreen&utm_content=pipedream_readme_pricing).

The action selects Chat Completions, Messages, or Responses from the chosen model’s published endpoint metadata and sends one synchronous request with `stream: false`. It returns the full native response, including `choices`, `content`, or `output` and usage as appropriate. Messages uses an output budget of 4096 when Max Tokens is omitted; this does not claim the model’s maximum capacity. The existing component key remains unchanged for saved workflows. It does not poll a media task, retry a paid request, choose a fallback or hide 4xx API errors. A timeout/408/5xx or missing choices requires checking original request/usage history before manual retry.
