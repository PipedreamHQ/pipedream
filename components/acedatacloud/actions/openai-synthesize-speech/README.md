# Synthesize OpenAI Speech

Synthesize speech through Ace Data Cloud and save the audio file. [See the documentation](https://platform.acedata.cloud/documents/openai-audio-speech)

Select this native action under the AceDataCloud connection and refresh Model options for the current API model list. The action sends one metered request without automatic retry or model fallback. Check account service access and current prices before running.
