# Decompose Seedream Image

Submit one Seedream 5.0 Pro layer decomposition request and return its `task_id`. This action does not wait for finished layers or retry a paid submission. Save the task ID; after the task lookup security gate passes, use Get Image Task with the same connected account.

The App registration request is [issue #22155](https://github.com/PipedreamHQ/pipedream/issues/22155). Check current Seedream pricing before running a paid request.
