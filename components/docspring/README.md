# DocSpring

Generate, combine, and sign PDFs from your DocSpring templates.

## Actions
- **Generate PDF** — fill a template and generate a PDF.
- **Combine PDFs** — merge submissions/templates/files into one PDF.
- **Create Data Request** — create a submission waiting for people to fill/sign it, and get a signing link per recipient.
- **Create Signing Link** — mint an authenticated link for a data request.
- **Find Template** — find templates by name or ID.
- **Find Submission** — get a submission by ID, or list recent submissions.

## Sources
- **New Event (Instant)** — emit an event when a subscribed DocSpring event occurs (webhook).
