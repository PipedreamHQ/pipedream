# Scamchecker

[Scamchecker](https://scamchecker.nl) checks suspicious messages — emails, SMS and WhatsApp texts — for signs of fraud, and can check a link on its own. Every check returns a verdict (`fake`, `suspicious`, `no_red_flags` or `unclear`) with the signals behind it, so you can automate triage instead of guessing.

This Pipedream component package includes:

| Action | Purpose |
| --- | --- |
| `check-message` | Check a suspicious message text or link and get a verdict with the signals found. |
