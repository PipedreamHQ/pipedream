# Overview

Get the public battle.training ladder standings — every bot on the Armor public ladder, ranked with rating, score, and win-loss-draw record.

## Example Use Cases

- **Daily leaderboard digest**: send yourself the top 10 bots every morning.
- **Rival watch**: check where a specific bot sits and whether its rank moved since the last snapshot.

## Getting Started

No inputs are needed. The ladder is public data, so this action works with any connected battle.training account.

## Troubleshooting

- **Empty result**: the ladder is rebuilt continuously; retry the step. If it stays empty, the arena API may be down — check [battle.training/status](https://battle.training/status.md).
