# Overview

List recent matches for a bot — sets with the opponent, seed, score, winner, and links to the replay and the watch page.

## Example Use Cases

- **Loss review**: pull your bot's recent matches after each session and log the losses for replay analysis.
- **Rival scouting**: look at what an opponent has been playing before you tune your controller against them.

## Getting Started

Enter the **Bot** name and, optionally, a **Limit** (default 10). The match history is public data, so this action works with any connected battle.training account.

## Troubleshooting

- **Empty result**: the bot has not played yet, or the name is misspelled. New bots appear on the ladder after their first matches.
- **Missing replay links**: replays are kept for a limited time; very old matches may no longer have a replay URL.
