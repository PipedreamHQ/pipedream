# Overview

List the battle.training ladders and sponsored cups — each ladder's slug, name, theater, and status. Use this to find valid ladder slugs for the **Get November Cup Standings** action.

## Example Use Cases

- **Find a cup slug**: list the open cups and pick the slug to check standings for.
- **Theater watch**: see which ladders are open across Armor, Silent Service, and Air.

## Getting Started

No inputs are needed. Ladders are public data, so this action works with any connected battle.training account.

## Troubleshooting

- **Empty result**: the ladder list is rebuilt continuously; retry the step. If it stays empty, the arena API may be down — check [battle.training/status](https://battle.training/status.md).
