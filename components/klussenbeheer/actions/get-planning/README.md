# Get Planning

## Overview

Fetches the jobs planned for today (`vandaag`), tomorrow (`morgen`) and the coming week (`komend`). No input is needed.

# Example Use Cases

1. Post the daily planning to a team channel every morning.
2. Send the crew a weekly overview every Monday.

# Getting Started

1. Connect the Klussenbeheer app with a Klussenbeheer token (Settings in Klussenbeheer).
2. Add the **Get Planning** action and run it.

# Troubleshooting

## The planning is empty

The response groups jobs by day. Jobs only appear here once they are scheduled in Klussenbeheer.
