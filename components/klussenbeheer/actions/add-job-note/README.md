# Add Job Note

## Overview

Adds a private note to a job. The note is only visible inside Klussenbeheer — nothing is sent to the customer.

# Example Use Cases

1. Log automation activity on the job, e.g. "Review request sent via workflow".
2. Store details from an email or form on the job for colleagues.

# Getting Started

1. Connect the Klussenbeheer app with a Klussenbeheer token (Settings in Klussenbeheer).
2. Add the **Add Job Note** action, pass the **Job ID** and write the note.

# Troubleshooting

## The customer did not receive anything

That is expected: notes are private. Use the Klussenbeheer app itself (or its customer communication features) to contact the customer.
