# Search Customers

## Overview

Searches customers by name, email address or phone number and returns up to 10 matches, with their ID, name, contact details and job count.

Use **Search Customers** before **Create Customer** to avoid duplicates, or to find the customer ID for follow-up automation.

# Example Use Cases

1. Look up the caller by phone number when a form or call tool passes a number.
2. Check whether a customer already exists before creating one from a contact form.

# Getting Started

1. Connect the Klussenbeheer app with a Klussenbeheer token (Settings in Klussenbeheer).
2. Add the **Search Customers** action and enter a search term, e.g. a name, email address or phone number.

# Troubleshooting

## No results

The search matches on partial values, but only on name, email address and phone number. Try a shorter search term, e.g. only the last name or the digits of the phone number.
