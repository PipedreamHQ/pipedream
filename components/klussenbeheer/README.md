# Klussenbeheer

[Klussenbeheer](https://samdesk.nl/klussenbeheer/) is job management for Dutch contractors and handymen (klussenbedrijven): customers, jobs, quotes, planning and invoicing in one place.

This Pipedream component package includes:

| Action | Purpose |
| --- | --- |
| `search-customers` | Search customers by name, email address or phone number. |
| `create-customer` | Add a new customer. |
| `create-job` | Create a new job. |
| `search-jobs` | Search jobs by title, customer name, address or phone number. |
| `get-job` | Get the full details of one job. |
| `add-job-note` | Add a private note to a job. |
| `get-planning` | Get the planning for today, tomorrow and the coming week. |

| Source | Purpose |
| --- | --- |
| `new-job` | Emit new events when new jobs appear. |
